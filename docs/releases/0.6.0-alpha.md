# Stash 0.6.0 Alpha

## Highlights

- 支持任意文件附件
- 新增 Backup / Restore
- 更成熟的桌面 UI
- 中文界面与中性主题
- 支持频道右键、条目右键和上下文“新建”
- Quick Stash 可直接选择保存频道
- 支持搜索频道与 Ctrl+K 快速选择
- Stable / Dev 数据隔离

## Data safety

- 安装器升级不会改变 Stable 数据目录。
- 数据库和附件继续保存在 Stable AppData profile 中。
- 升级或卸载不会删除用户数据。
- 强烈建议升级前手动创建 Backup，并将备份保存在 Stash 安装目录之外。

## Known limitations

- 当前仍为 Alpha 软件。
- 安装器尚未进行代码签名，Windows SmartScreen 可能显示警告。
- 暂不包含 Android 与 Sync。
- 暂不支持自动更新。
- Quick Stash 按设计不会记住上一次选择的频道。
